# PhishGuard Phase 5 – Browser Implementation

This folder contains the Phase 5 browser-based implementation. It is a local Python HTTP server with an HTML/CSS/JavaScript interface and a rule-based detection engine. It uses only the Python standard library.

## Run
1. Download or clone the repository.
2. Open `Phase5_Web_Implementation` in a terminal.
3. Run `py app.py`.
4. Open http://127.0.0.1:5000 in a browser.
5. Run tests with `py -m unittest discover -s tests -v`.

The application is for educational demonstration only. Do not expose the local server publicly or submit confidential email content.
